# Gerinctorna

Saját napi gyógytorna-oldal (15 gyakorlat a gyógytornász lapja alapján) egyetlen HTML fájlban: `index.html`.

- Mozgó figurák minden gyakorlathoz, kiemelt végtagokkal és irány-nyilakkal
- Időzítő sorozatokkal, pihenővel, oldalcserével; megállítható, léptethető
- Ismétléses gyakorlatoknál tempóra mozgó figura és hangos számolás
- Hangjelzés, magyar bemondás, a képernyő ébren marad torna közben
- Gyakorlatonként átírható sorozat / idő / ismétlés, ki-be kapcsolható gyakorlatok
- Napló: sorozat-naptár, fájdalom-értékelés (0–10) és megjegyzés a gyógytornásznak

Megnyitás: https://raw.githack.com/lipoczit/gerinctorna/main/index.html
(vagy GitHub Pages bekapcsolása után: https://lipoczit.github.io/gerinctorna/)

A beállítások és a napló csak a böngésző helyi tárolójában vannak, a repóba nem kerülnek.
